## 结论

纯向量召回在当前黄金集上表现稳定：Recall@5 达到 100%，MRR@10 为 89.91%。当前 Rerank 配置没有带来收益，Candidate K=20、Final K=3 的 MRR@3 比纯向量 MRR@3 低 30.70 个百分点，因此暂不建议接入线上链路。

该结果存在两个限制：

1. 19 条正向用例目前每条只标注一个黄金文档，因此 Precision@K 的理论上限为 `1/K`，概念库中其他合理文档也会被严格计为未命中。
2. 免费账户受 10K TPM 限制，Top30 Rerank 只使用每个候选的标题和 160 字符正文摘要，并非完整分块；后续应增加多级相关性标注并优化 query-aware 摘要或提高吞吐限制后重新评测。

完整逐题结果由 `scripts/evaluate_rag_retrieval.py` 在本地生成，报告不会提交第三方正文或 API 凭据。
