# AlgoMate RAG 数据说明

本目录在 Git 中只保留数据设计说明和人工编写的黄金测试集。抓取原文、清洗语料、Embedding 缓存、Milvus 数据和逐条评测报告均在本地生成，并通过 `.gitignore` 排除，以避免提交第三方网页正文、密钥或可再生的大型文件。

## 四类知识源

| 知识源 | 内容 | 当前检索方式 |
| --- | --- | --- |
| 算法概念库 | 代码随想录专题、方法与学习路线 | `voyage-4` + Milvus |
| 题库 | LeetCode 题面、示例与约束 | `voyage-4` + Milvus |
| 代码案例库 | 与题目一一配对的高质量题解和代码 | `voyage-code-4` + Milvus |
| 用户私有记忆 | 会话目标、偏好、约束和学习轨迹 | 会话隔离的文本召回 |

当前入选向量计划包含：

- 算法概念库：297 篇文档，1,767 个分块。
- 题库：106 篇文档，109 个分块。
- 代码案例库：106 篇文档，175 个分块。
- 总计：509 篇文档，2,051 个向量分块。

题库和代码案例库使用相同 `document_id` 建立一题一解关联。代码案例清洗阶段移除评论区、登录提示、导航和其他页面噪声，并保留作者、点赞量、浏览量及原始来源元数据供审计。

## 本地目录

运行数据流水线后可能出现：

```text
rag-data/
├─ raw/                    # 原始抓取结果与来源清单（不提交）
├─ processed/              # 清洗、去重后的语料（不提交）
├─ vector/                 # 分块、Embedding checkpoint、Milvus（不提交）
└─ evaluation/
   ├─ rag-test-cases-v1.json   # 人工黄金测试集（提交）
   ├─ cache/                   # 查询向量与 Rerank 缓存（不提交）
   └─ reports/                 # 完整逐条报告（不提交）
```

## 评测

黄金测试集当前包含 20 条查询：7 条概念、6 条题库、6 条代码案例和 1 条库外问题。评测脚本支持 Candidate K `5/10/20/30`、Final K `1/3/5`，并计算 Hit、Precision、Recall、F1、MRR、MAP、nDCG、空结果率、错库率和重复文档率。
